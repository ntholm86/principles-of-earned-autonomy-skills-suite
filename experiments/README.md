## Deletion boundary

Deleting this directory is not currently a safe cleanup. It would remove direct support for claims in `.acm/destination.md`, `.acm/orientation.md`, and the append-only Trail. Because the files are committed, deleting them from the working tree would not remove their bytes from Git history without destructive history rewriting.

Archive or remove a package only after its durable claims identify a replacement evidence location, all live references are updated, and repository verification confirms that the remaining record is independently inspectable. Historical Git reachability alone is not a replacement for a current evidence path.
